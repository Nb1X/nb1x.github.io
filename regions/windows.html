Windows tutorial
1
Download the regionInfo.json file.
2
Press Win + R on your keyboard. A window should open.
3
Type exactly this (do not remove the quotation marks):
"%userprofile%\AppData\LocalLow\Innersloth\Among Us"
4
Copy the regionInfo.json file you downloaded and paste it in the folder that opened in File Explorer.
5
Launch Among Us through your usual launcher (Steam, Epic, Itch.io ....) and open the Find Game menu. Select the ModdedCrew region.

Only the 4 first steps should be done once.
The ModdedCrew region is added forever until you edit the regionInfo.json!
